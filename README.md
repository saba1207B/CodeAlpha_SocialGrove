# Social Grove 🌿

> A mindful, thoughtful corner of the web for ideas worth keeping.

Social Grove is a modern, responsive social media platform focused on slow mornings, creative craftsmanship, and unhurried reflections. Built with React, TypeScript, Tailwind CSS, and tRPC.

![Social Grove Preview](https://images.unsplash.com/photo-1506744038136-46273834b3fb?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **Mindful Feed**: Read and share thoughtful notes with tags like `#slowmornings`, `#madebyhand`, `#smalljoys`, and `#quietplaces`.
- **Photo Attachments**: Upload and display high-resolution imagery alongside your notes.
- **Interactive Engagement**: Like notes, save bookmarks to your personal collection, and reply with threaded discussions.
- **Circle & Following**: Discover fellow makers, ceramicists, landscape painters, and essayists to follow.
- **Personalized Profiles**: Customize display name, handle, bio, and curated avatar color accents (Terracotta, Olive, Plum, Sand, Blue).
- **Responsive Navigation**: Clean editorial sidebar with instant tag filtering, search, notifications, and modal composer.
- **Offline / Static Demo Support**: Automatic local storage fallback when previewed statically or on GitHub Pages.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **API & Data Layer**: tRPC v11, TanStack Query v5, SuperJSON
- **Backend**: Node.js, Express, Drizzle ORM
- **Build Tool**: Vite 7
- **Deployment**: GitHub Pages via GitHub Actions

## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/saba1207B/CodeAlpha_SocialGrove.git
   cd CodeAlpha_SocialGrove
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

4. Run tests & type checks:
   ```bash
   npm run check
   npm run test
   ```

5. Build for production:
   ```bash
   npm run build
   ```
